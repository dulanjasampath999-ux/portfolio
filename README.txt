# Personal Portfolio Website

A clean, responsive, publish-ready portfolio template.

## Files
- index.html — main page
- style.css — all styling
- script.js — mobile menu + scroll animations
- assets/ — place your photos, CV, project images, etc. here

## Customize
Search and replace:
- "Your Name"
- "you@example.com"
- "Sri Lanka"
- social links (#)
- project titles/descriptions
- skills/about text

For the hero image, you can replace the "YN" block in index.html with:
<img src="assets/profile.jpg" alt="Your Name">

## Publish
This is a static website, so it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or normal cPanel hosting.

No database or server is required for the current version.
